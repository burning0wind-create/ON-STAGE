# ON STAGE · 产品定义与需求映射

版本：0.1.0；日期：2026-10-30。

## 定位

面向准备设计学及相关专业推免、研究生复试、海外升学面试的学生。核心任务是围绕真实简历与作品集，在目标院校、专业、年份和招生类型的考核约束下，练习解释设计过程、研究判断与个人观点。

本仓库提供可运行的本机单用户原型。参考此前“梳理多模态AI模拟面试流程”项目及同一工作区保存的 ON STAGE 第二版设计说明、品牌规范和考官模块说明。旧聊天因单轮内容超出读取上限未能直接载入；不将缺失的流程细节视作已确认需求。

## 体验流程

1. 面试练习：按环节开始或新建整场，回看自己的真实记录。
2. 面试设置：选择院校专业、年份、招生类型，填写昵称、时间和次数。
3. 上传材料：简历、作品集、考核细则、评分标准；确认提取文字与补充说明。
4. 确认规则：配置本场环节和时长；录入有来源的院校评分项。未提供权重时，只生成训练反馈。
5. 设备检查：摄像头预览、麦克风连接；手部与眼动尚未接入时显示未接入。
6. 七层预分析：目标考核、学生与作品、考官、提问策略、证据缺口、评分、节奏。
7. 模拟面试：一题一答，转写可修正，回答后继续追问或切换环节，允许暂停恢复。
8. 结果复盘：院校练习分与训练分分开、回答原文、改进清单、可比历史与导出。

## 多模态实现边界

| 通道 | 本版状态 | 后续工作 |
|---|---|---|
| 文本 | 已实现；材料文字、问答记录、证据引用校验 | 更细的页码引用与知识校验 |
| 音频 | 浏览器语音转写与问题朗读，受浏览器服务可用性影响 | 流式 ASR、词级时间戳、服务端录音与播放同步 |
| 摄像头 | 本机预览、开关事件 | 在明确采集授权后接入视频回放与非诊断性表现指标 |
| 作品图像 | 原件保存与查看；PDF 提取文字，图片/扫描件需说明 | 多模态模型、OCR、逐页视觉理解与证据定位 |
| 手部传感器 | 事件接口与未连接状态 | 硬件协议、校准、丢帧与质量指标 |
| 眼动仪 | 事件接口与未连接状态 | SDK、时间同步、校准与用户可理解的反馈 |

不通过表情、眼动、手势推断道德品质、政治观点、人格、心理疾病、录取潜力。院校要求的道德、价值观等考察被实现为可配置的问答内容，评价只依据回答与上传细则，不作真实招生决定。

## 版本路线

- V0.1：本机可运行，材料与环节、预分析、问答、分数证据、报告与 GitHub 项目文档。
- V0.2：院校规则结构化提取与人工确认，PDF/作品视觉理解，逐题音视频回放，流式语音服务。
- V0.3：眼动/手部适配器、统一时间轴、信号质量标记；用学生与教师双评样本校准评分。
- 部署版：账户隔离、数据库、加密与删除、授权与留存管理、生产鉴权、模型费用与限流。当前不能直接作为公开多用户服务部署。
