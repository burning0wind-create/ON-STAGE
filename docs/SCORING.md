# 证据评价、评分标准与校准

## 两套标准与独立表达反馈

院校标准来自对应学校、学院、专业、方向、招生年份和招生类型的官网规则或学生上传并确认的材料。官网考核库保存来源、发布日期、核验日期和适用范围。笔试、材料审查、面试内部评分与录取总成绩公式分别记录，不互相替代。未知内部权重留空，不能将列出的能力平均分配权重。本批库只有湖南大学2027推免公开完整面试分项20/40/40，可直接载入结构化院校评分；其余条目保留已公布内容及未公布项。

专业训练标准由 ON STAGE 拟定，共12种专业/方向量表。每种包含6个专业维度，分别重写评价标准、1/3/5行为锚点、所需证据与下一步追问，权重合计100%。实际匹配先采用目录专业及方向ID，再采用明确的自定义方向或专业，不能从学院名称或简历关键词猜测专长。详见 [方向量表映射](RUBRICS.md) 和 public/rubrics.js。这些训练权重未经评分效度校准，不是院校官方考核细则，也不是 Interview Master 发布的设计升学评分表。

表达反馈另设语义清晰度、表达组织与详略、专业措辞与任务沟通3项，不计入专业训练总分。表达流畅不能代替专业知识、论证和设计判断；文字也不能证明发音、口音、语气或真实语速。

## 借鉴的证据规则

参考 [Interview Master 的证据评价规则](https://github.com/chen3tu/interview-master-skill/blob/main/references/interview_evaluation_criteria.md)，将以下原则落实为服务端校验和界面，而非安装或调用该技能：

- 面试开始前生成并冻结本场量表；报告和导出保存版本、权重及行为锚点。
- 将能力覆盖与回答质量分开，未考察不等于低分，答错属于有证据的质量判断。
- 每条非空评分关联题目ID、回答ID、环节、回答原文、理由、证据边界和下一步追问。
- 同一维度重复引用规范化后相同的回答原文，只算一条独立证据，不因重复作答提高分数。
- 反证及其引发的评价修正必须可见；反证引文同样需逐字存在于实际回答中。
- 正式模拟中隐藏逐题评分与改写示例，结束后再复盘。看过改写示例后的练习应作为辅助练习，不能直接当作独立能力证据。
- 每场优先保留1–2条可执行改进，并展示相应改写建议和小练习。

## 观察状态与计分

| 状态 | 含义 | 质量分 |
|---|---|---|
| observed 已观察 | 本题有足以判断该能力的回答证据 | 1–5 |
| partly_observed 部分观察 | 可以评价已出现的部分，但能力范围仍不完整 | 1–5，不能冒充完整覆盖 |
| not_assessed 未考察 | 本题没有考察该能力，或当前环节不适用 | null |
| skipped 已跳过 | 学生主动跳过题目 | null |
| insufficient_evidence 证据不足 | 已涉及该项但尚不能作可靠质量判断 | null |

2/4分介于相邻行为锚点之间。已观察和部分观察都需要分数及完整证据记录；其余状态不得评分。后端验证引文逐字存在于对应回答、题目与回答ID相符，并验证当前环节适用性。引文存在只能防止虚构引文，不能证明学生经历真实或专业评价正确。

单维质量分取该维独立有效观察的平均值，包含已观察及部分观察，保留一位小数。专业训练总分 = Σ（该维质量分 / 5 × 权重）。只有全部专业维度均已观察、所有关键维度覆盖完整，且不是辅助练习或缺少新版状态的历史记录，才计算总分；否则展示分项和待补证追问。跳过不补零，重复引文不再次计分。表达分数和设备状态不影响专业分。

院校标准的每项质量评分为0–100，按当场确认权重合成练习总分。任一项未考察、跳过、证据不足或仅部分观察时保留分项，不计算完整院校练习总分。它不代表真实招生考试成绩、通过概率或录取结论。

## 无模型、历史与跨次比较

未连接模型或模型响应未通过校验时，仍保存回答，但不生成能力分数，不以连接词数、回答长度、数字数量或设备状态替代专业评价。演示模式可完整体验提问、跳过和结束流程，报告明确显示未评估。

历史报告保留原量表和已有结果，不伪造新版观察状态。跨次比较需目标、方向、年份、招生类型、本场标准指纹、量表ID/版本及运行模式等一致；仅比较两场都已观察且有分数的维度。

Markdown/JSON导出保留量表快照、官方来源、确认文本、覆盖状态、证据账本、反证修正、优先改进和对话。导出不能把 null 渲染为0。

## 内容与多模态边界

转写文字用于评价回答内容和措辞；专业词转写允许学生提交前修正。提交计时包括思考和编辑，不是声学说话时长。当前版本不从纯文本评分英语发音和口音，也不自动分析作品集画面的美学或技法质量。

摄像头、眼动和手部信号不参与内容得分，不据此推断人格、道德、政治倾向、心理状态或录取概率。设计伦理只针对回答中明确讨论的贡献、引用、授权和利益取舍给出证据反馈。

## 校准计划

- 按招生类型与设计方向收集已获授权的匿名练习回答，覆盖强、中、弱与不确定样本。
- 至少两名熟悉相应专业的教师独立评分，记录分歧，校正权重、行为锚点与适用环节。
- 比较模型与教师的分项误差、一致性和重复评分波动，检查不同语言背景的差异。
- 检查“流畅但内容错误”“简短但推理正确”“转写错误”“无量化数字但论证扎实”等对照样本。
- 固定模型、提示词、量表版本和评估数据版本；标准变化后不直接拼接旧分数趋势。

校准完成前，产品用于面试练习反馈，不宣称可替代真实招生评价。
