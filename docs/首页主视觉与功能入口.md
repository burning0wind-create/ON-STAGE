- 桌面主视觉按可用视口高度扩展。1366×768时高度656px，约占视口85%；1920×1080时高度968px，约占90%。保留页面边缘留白。
- slogan保持“下一场面试，准备更充分。”。使用用户提供的PingFang SC Semibold生成矢量轮廓，再进行8度斜切、两行错位，以及“准备”实心、“更充分”描边的对比排版。
- 艺术字资源：`public/assets/home-slogan.svg`；可编辑的文案与变换源文件：`scripts/export-home-slogan.mjs`。可运行该脚本重新导出，无需外部字体或网络服务。
- 矢量字通过蒙版继承当前文字颜色，保持深浅模式及青绿、蓝色、紫色、黑白配色联动。标题仍保留可访问的中文文本与h1语义。
- 背景继续使用既有O＋S标志的裁切曲面与细弧线。导航只保留原侧边栏，原记录中的查看复盘/继续面试操作仍可使用。
