# 采集状态标签配色

“等待输入”、计时器、“正在记录”和识别状态的底色及文字色统一使用配色变量，不再固定为深绿色。录制状态、时间格式、识别及设备连接逻辑不变。

| 配色 | 底色 | 文字色 | 浏览器核对的对比度 |
|---|---|---|---:|
| 青绿 | #102a22 | #e5f3eb | 13.3:1 |
| 蓝色 | #112239 | #eef4ff | 14.5:1 |
| 紫色 | #241b35 | #f4efff | 14.5:1 |
| 黑白 | #181a1d | #f7f7f7 | 16.3:1 |
| 深色模式 | #101c16 | #e5efe8 | 14.9:1 |

变量与选择器集中在 `public/palette.css`，主界面和多模态iframe沿用现有主题同步机制，切换即时生效。深色模式保持既定薄荷绿与中性色，不跟随浅色紫色产生混搭。

检查时另修正中等窗口采集布局规则的选择器优先级，避免内部姿态区域在双层分栏后被挤窄。未开启摄像头或IMU，未写入新的面试记录。
