# 模型连接设置

刷新 http://127.0.0.1:4318/ ，点击侧边栏底部“模型设置”。收起状态下为芯片图标。

1. 填写服务商提供的接口基础地址（不含 `/chat/completions`）、模型名称或接入点 ID、API 密钥。
2. “测试连接”只发送固定测试文本，不保存设置、不发送面试材料。
3. “保存并启用”会验证连接，成功后保存到项目根目录 `.env.local`，立即启用，无需重启。后续回答及新建场次使用该模型；历史回答暂不自动补评。

接口兼容 Chat Completions。远程地址使用 HTTPS，本机服务允许 HTTP。连接失败会显示提示，保留原配置。更换接口地址需重新填写密钥，避免将原服务商的密钥发往新地址。

密钥不会回传到页面，也不写入浏览器存储。再次打开时密码框为空，留空保持原密钥。`.env.local` 属于本机配置，源码打包脚本会排除它。启用模型后，评分会将面试材料与回答发送到所配置的接口。

本次验证：80 项自动测试通过，52 个 JavaScript 文件语法检查通过；浏览器验证入口、配置读取、错误提示、浅色与深色显示。未配置真实密钥，未执行真实模型评分。
