# 屏幕适配

模式：Extension，保留既有产品结构、路由、真实记录、表单与采集状态。沿用青绿主色及现有蓝/紫/黑白配色、深浅模式、PingFang SC、12/16/40/64px字体等级、0.5px边框。仅调整布局。视觉变化2/10、动态1/10、信息密度5/10、素材依赖3/10、品牌保持10/10。

布局依据浏览器可用宽度（包括系统缩放、浏览器缩放和分屏造成的变化），不读取显示器型号，不把页面整体缩小。

- 大窗口保持有上限的居中内容区，首页双栏，评分卡片按空间排列。
- 721–1180px窗口自动收起侧边栏，可手动展开。自动切换不覆盖用户存储的偏好，回到宽窗口时恢复该偏好。
- 内容区小于940px时首页、面试主区域与双栏报告逐步改为单栏，表单两列；小于620px时表单与详细内容单列。
- 480px及以下将Logo、设置按钮和导航分行放置，避免互相遮挡。长导航及表格在各自区域滚动，不挤出整页。
- 多模态模块按iframe实际宽度排列；评分卡片最小约260px，空间充足时三列，中等时两列，较窄时单列。摄像头保持16:9，姿态控制与回放对话相应重排。
- 低于800px高的桌面窗口减少侧边栏垂直间距；若仍放不下可单独滚动。长复盘重新计算iframe高度，避免窄屏换行后被旧高度上限截断。

实现：主页面 `public/responsive.css`，采集与复盘 `public/multimodal/responsive.css`，侧边栏自适应逻辑 `public/shell.js`。窗口尺寸变化只改变布局，不重新渲染表单，不重新连接设备、不重置复盘位置。

## 验证

浏览器检查1920×1080、1366×768、1024×768、768×1024、390×844、320×640。首页六种宽度均无整页横向溢出；设置、考核库、资料、设备页在1366/1024/390px下逐页检查通过。复盘页六种宽度均检查了iframe实际宽度与卡片列数；320px下的长表格在局部容器内滚动。模型设置弹窗在320px宽、640px高下可以滚动访问完整内容。

选中手部片段01:05.4后改变窗口宽度，选中时间保持65384毫秒。未在本次测试中启用摄像头或IMU，未新增面试记录。87项既有自动测试通过；Windows受限临时目录的rename测试曾遇到EPERM，改用项目专用临时目录并获准重跑后全部通过。
