# 按目标专业与方向的证据训练量表

版本：`onstage-evidence-v1`。本表由 ON STAGE 为升学面试训练编写，借鉴 [Interview Master 的证据评价规则](https://github.com/chen3tu/interview-master-skill/blob/main/references/interview_evaluation_criteria.md)。院校官网目录仅用于确认报考目标、专业代码和研究方向，不是下列权重或行为锚点的来源。

所有权重均为**暂定训练建议**，不代表任一学校的官方标准，也未经教师双评或效度研究校准。院校评分继续由用户上传、确认的对应专业考核细则独立决定。

## 评价契约

- 在学生作答前选定目标、说明训练范围并保存量表版本；不能回答后再调整标准以改变分数。
- 每项评价应连接本场具体问题、回答 ID 和原文片段，并说明质量判断、事实边界及下一追问。
- 质量与覆盖分开：“未考察、部分观察、跳过、证据不足”不是“答错”。缺少证据不补零，必要能力未观察时只给局部结论。
- 同一段文字可关联不同能力，但重复展示、重复背诵或同一错误不能冒充新的独立证据。
- 专业判断看本题中的知识理解、推理、证据和取舍。简历与作品中的自述不是独立验证；专业词转写存疑应先确认。
- 语言表达单独反馈。仅有文字时不评价发音、语速、停顿、语气；不以口音、人格、表情、眼动或手势替代专业能力。
- 反例或后续澄清可以改变结论，应保留修正。复盘优先给一到两项高价值改进、针对性回答改写和下一次练习。

## 目标匹配

优先使用已确认目录中的 `programId + directionId`；同名方向不会跨学院串用。没有细分方向的“设计学”保留通用研究量表，不能从“数字科技”等学院名称或作品关键词猜测专业。自定义院校的明确方向名称可用于暂定匹配，但不改变官方目标。

| 训练类别 | 主要关注点 | 六维建议权重：论证／知识／证据／决策／反思／伦理 |
|---|---|---|
| 设计学研究 | 研究问题、方法适用性、资料边界、竞争解释 | 25／20／20／15／15／5 |
| 设计专业实践 | 需求转译、实践过程、方案取舍、迭代验证 | 20／15／20／25／15／5 |
| 交互与体验 | 使用任务、用户研究、交互机制、可用性与可达性 | 20／15／25／20／15／5 |
| 视觉与媒体传播 | 受众、信息层级、视觉语言、媒介与理解证据 | 20／25／15／20／15／5 |
| 产品与工业设计 | 任务、人机、结构、材料工艺、模型与安全 | 15／20／20／25／15／5 |
| 环境与空间 | 场地、行为、空间组织、实施运营与公共影响 | 20／15／20／25／15／5 |
| 设计历史与理论 | 概念语境、史料层级、互证、解释竞争 | 25／25／25／10／10／5 |
| 服饰、材料与工艺 | 材料与制作条件、身体使用、文化转译、工艺协作 | 15／25／20／20／15／5 |
| 美术创作与艺术理论 | 创作命题、媒介语境、过程资料、解释开放性 | 20／25／20／15／15／5 |
| 技术与设计交叉 | 技术机制、本人实现、原型条件、可靠性与降级 | 15／20／25／25／10／5 |
| 人工智能与数据设计 | 数据表示、样本与基线、泄漏偏差、误差代价和人机责任 | 20／20／25／20／10／5 |
| 服务系统与设计战略 | 多方价值、后台组织、运营、试点与长期反馈 | 20／15／20／25／15／5 |

`087200` 人工智能与数据设计采用独立的数据评价标准；`085400` 的设计相关方向与 `085507` 数智交叉强调技术机制、原型与实现边界，不能只凭“智能”一词互换。已选交互方向时仍以交互任务与验证为核心，技术实现只是实际观察到时才讨论的证据。

## 专业表的结构

每套量表都保留六个稳定 ID：`logic`、`knowledge`、`evidence`、`decision`、`reflection`、`ethics`。但各类别的评价要求、1／3／5 分行为锚点、需要的证据和追问均实质重写。

例如，同为“证据”维度：

- 交互方向要看任务、参与者、观察与原型改动之间的关系。
- 工业设计要区分效果图、制作模型和已完成的使用或性能试验。
- 史论方向要区分一手材料、二手解释和个人推断，讨论材料立场与互证。
- 人工智能与数据设计要说明数据形成、基线、评价划分、代表性与泄漏风险。

每项有关键能力标记。研究类侧重论证、知识、证据与反思；实践类侧重论证、知识、证据与决策。标记只是训练范围约束，不宣称学校把这些能力规定为合格门槛。

## 独立的语言表达表

三项：语义清晰度、表达组织与详略、专业措辞与任务沟通。权重为 0，表示不进入专业训练总分，并非表示语言不重要。

英语问答可依据转写观察是否回应问题、意思是否清晰、术语解释是否适当。不能从转写推断发音、口音、语气或真实流利度。回答结构是否易懂与专业论证是否成立应分别判断，不能因连接词多、语言流畅而抬高专业分。

## 维护与校准

实现位于 `public/rubrics.js`，浏览器和服务端共用纯函数 `buildTrainingRubric(target)`，返回可序列化的量表快照。修改要求或权重时增加版本，不重写历史场次的量表。比较历史需核对目标、方向、版本与评分依据。

后续由目标方向教师独立标注匿名回答，比较分项误差、一致性和重复评分波动，检查“表达流畅但内容错误”“没有数字但论证扎实”“术语被转写错”“同一例子重复回答”等对照样本后再调整权重与锚点。
